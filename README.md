## 📌 Proyectos Destacados

### 🚲 1. [Jardín-Bike](https://github.com/richartorres/Jard-n-Bike)
> **Repositorio Público** | Arquitectura Backend y Gestión de Flotas
- **Descripción:** Plataforma web para la administración y alquiler de bicicletas eléctricas en Jardín, Antioquia.
- **Aspectos Destacados:** Autenticación de usuarios, gestión de estado de flota, transacciones de préstamos e implementación de ORM/migraciones en Laravel.
- **Tech Stack:** `PHP`, `Laravel`, `MySQL`, `Git`

### 🛠️ 2. [Soporte Pro](https://github.com/richartorres/soporte_pro)
> **Repositorio Público** | Sistema HelpDesk & Gestión de Incidencias
- **Descripción:** Solución de software orientada a la centralización y resolución de solicitudes de soporte técnico y diagnósticos de hardware.
- **Aspectos Destacados:** Gestión del ciclo de vida del ticket, módulos de diagnósticos preventivos y control de estados de servicio.
- **Tech Stack:** `PHP`, `MySQL`, `Apache (XAMPP)`, `HTML5/CSS3`

### 💒 3. [My-Boda](#)
> **Repositorio Privado** | Sistema de Logística y Planificación
- **Descripción:** Plataforma web para el control operativo, seguimiento presupuestario y confirmación de asistencia en tiempo real.
- **Aspectos Destacados:** Módulos de gestión financiera, confirmación RSVP e interacción dinámica basada en tipos estrictos de dominio.
- **Tech Stack:** `TypeScript`, `Node.js`, `React`
